# Внутренние эндпоинты TOBIZ, формат ответов и границы

Публичного API у конструктора нет. Сервер `tobiz-mcp` ходит по внутренним адресам редактора и
панели под сессией конструктора (cookie `session` + `email`). Ниже — то, что нужно знать, когда
результат инструмента не совпадает с ожиданием.

## Адреса

| Адрес | Назначение |
| --- | --- |
| `POST /system/ajax.php` | панель: список проектов и страниц, параметры страницы, копирование и удаление |
| `POST /system/editor/ajax.php` | редактор: блоки страницы, создание, сохранение, дефолты, группы секций |
| `POST /system/editor/upload.php` | загрузка изображений (нужен `block_id` реального блока) |
| `GET /js/blocks2.js` | catalogue шаблонов блоков (162 типа) |
| `GET /json/sections.json` | палитра блоков: 28 категорий, 486 записей |
| `GET /json/stylesFontsPresets.json` | пресеты шрифтов/стилей сайта — сюда смотреть за типографикой |

## Действия панели (`/system/ajax.php`)

| `action` | Поля | Что делает | Инструмент |
| --- | --- | --- | --- |
| `get_projects` | — | HTML со списком проектов и страниц (это единственный способ узнать страницы) | `tobiz_list_projects`, `tobiz_list_pages` |
| `edit_page_form` | `page_id` | HTML-форма параметров страницы (название, slug, SEO, og:image, пароль) | `tobiz_page_info` |
| `edit_page` | `page_id`, `page_title`, `page_dir`, `page_user_personal_seo_configs`, `page_seo_title`, `page_seo_keywords`, `page_seo_description`, `page_valid_login`, `page_valid_password` | изменение параметров страницы | `tobiz_update_page` (шлёт форму целиком, read-modify-write) |
| `copy_page_to_anp_form` | `page_id` | HTML-форма копирования (список проектов) | `tobiz_copy_page(apply=false)` |
| `copy_page_to_anp` | `page_id`, `page_title`, `new_project` | копирование страницы в проект | `tobiz_copy_page(apply=true)` |
| `delete_page` | `page_id` | удаление страницы | `tobiz_delete_page(confirm=true)` |

`edit_page` требует **всю форму**: если отправить только часть полей, остальные будут очищены.
Поэтому инструмент сначала читает `edit_page_form`, подменяет нужное, отправляет и перечитывает —
расхождения возвращает в `mismatched`.

## Действия редактора (`/system/editor/ajax.php`)

| Действие | Что делает |
| --- | --- |
| `GetBlocks` | блоки страницы (значения + сохранённый HTML); требует `rep_id` |
| `GetBlock` | значения одного блока. Для блока текущей страницы отвечает «Нельзя отобразить блок с текущей же страницы» — это нормально |
| `CreateNewBlock` | добавить блок из библиотеки |
| `SaveBlocks` | записать страницу: сервис отправляет **перерендеренный HTML всех блоков** — без `cache` блок исчезает |
| `GetSectionGroups`, `GetRandomSectionByGroupId` | категории и случайный блок категории |
| `fetchSectionDefaultValues` | серверные дефолты полей типа блока (151 тип) |
| `GetHeaderIDs` | id блоков-шапок |
| `refreshPageEditoTime` | продление «времени редактирования» страницы |

## Формат ответов

```json
{"status": "OK",    "respons": "<строка JSON>"}
{"status": "ERROR", "respons": "текст ошибки"}
```

Ответ часто **двойным кодированием**: `respons` — строка, внутри которой лежит JSON. Значения
полей-объектов тоже иногда приходят строкой JSON (сервис декодирует до 3 уровней).

## Коды, которые возвращает сервер MCP

| Код | Что значит | Что делать |
| --- | --- | --- |
| `AUTH_FAILED` / `AUTH_CAPTCHA` | сессия конструктора недействительна | положить `cookies.json` (`session` + `email`) в том сессии или задать `TOBIZ_EMAIL`/`TOBIZ_PASSWORD` |
| `UNKNOWN_TYPE` | неверный `type_id` (частая причина — передан `block_type_id` вместо `type_id`) | взять тип из `tobiz_search_blocks` |
| `BAD_ARGUMENT` | значение не подходит по схеме (например, `select` передан числом, `delete_page` без `confirm`) | привести к строке/добавить флаг |
| `NOT_FOUND` | нет такого `block_id`/`page_id` на этой странице | перечитать страницу |
| `RENDER_FAILED` | блок не отрендерился шаблоном вендора | проверить значения полей (обычно значение не из списка) |
| `UPSTREAM_UNAVAILABLE` | конструктор не ответил | повторить: черновик живёт в памяти сервиса |

## Границы, проверенные на живом аккаунте

* **Загрузка изображений** работает на бесплатном тарифе, но только с `block_id` реального блока
  страницы: без него `#2`, с посторонним id — `#3`. Файл больше ~30 МБ отбивает nginx (`413`).
* **Блоки без шаблона** (архивные, часть flex- и товарных) правятся частично: меняются только
  значения верхнего уровня.
* **9 типов блоков** требуют данных и отсутствуют в библиотеке; **5 видео-блоков** чувствительны к
  пустым дефолтам.
* **`?v=<число>` в публичном URL — это id страницы**, а не параметр кеша: свои значения с `v`
  дают 404.
* **Стили сайта** (общие для всех страниц) живут в CSS-переменных вида
  `--styles_btn_radius`, `--styles_btn_bg_color`, `--styles_link_color`. На страницу их не выставить
  — они настраиваются в панели сайта. Если нужен именно такой эффект (например, цвет ссылок),
  сообщи об этом: нужен эндпоинт стилей сайта, его у сервиса пока нет.
