# Каталог блоков TOBIZ: какая категория для чего

Источник — `/json/sections.json` проекта (то, что редактор показывает в палитре блоков).
Категория = задача, `type_id` = конкретный шаблон для `tobiz_add_block`.
Перед вставкой смотри `tobiz_describe_block`: у каждого типа свой набор полей.

Всего категорий: 28, типов: 486.
